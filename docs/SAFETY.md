# Безопасность и восстановление

## Перед записью

* Зажигание **ВКЛ**, двигатель **ВЫКЛ**, скорость 0, все двери закрыты (если не нужно иное).
* Напряжение **> 12 В**, лучше подключить зарядное/бустер: MIB3 и BCM при просадке могут сбросить
  запись на полпути. `vagon info` показывает напряжение на разъёме.
* Не трогайте зажигание и не отключайте адаптер, пока идёт запись (секунды).
* На некоторых MQB запись проходит только с **открытым капотом** («диагностический firewall»).

## Что VagOn делает при каждой записи

1. Читает текущее значение заново (не из кэша) и сравнивает длину с тем, что собирается записать.
2. Сохраняет резервную копию: `~/.vagon/backups/<VIN>/<время>_<блок>_<причина>.json` (идентификация
   блока + старые значения всех изменяемых DID).
3. Открывает сессию, при необходимости — логин (один раз; неверный код не повторяется).
4. Пишет F199 (дата программирования) и F198 (код мастерской = текущий F1A5), как ODIS/VCDS.
5. Пишет данные, затем читает их обратно и сравнивает. Несовпадение — ошибка с путём к копии.
6. Записывает результат в журнал `~/.vagon/journal.jsonl` (`vagon journal`).

## Откат

* Рецепт: `vagon recipe off <id>` (по значениям `off` или из копии, сделанной при включении).
* Любая запись: `vagon backups` → `vagon restore <файл>` (покажет, что изменится, и спросит).
* В веб‑интерфейсе: «Ещё → Копии» → нажать на копию.

## Ошибки блоков (NRC) и что они значат

| Код | Значение | Что делать |
|---|---|---|
| 0x33 | доступ запрещён | Нужен логин‑код; если логин принят, а запись всё равно запрещена — **SFD** |
| 0x35 | неверный ключ | Неверный логин‑код. VagOn не повторит его. |
| 0x36 / 0x37 | слишком много попыток / задержка | Подождать ~10 мин с включённым зажиганием |
| 0x22 | условия не выполнены | Зажигание, двигатель, скорость, напряжение, капот |
| 0x31 | вне диапазона | Значение/идентификатор не поддерживается этой версией ПО — рецепт не подходит |
| 0x13 | неверная длина | Рецепт рассчитан на другой блок |
| 0x24 | неверная последовательность | Блок ждёт другой порядок шагов |
| 0x7F | не в этой сессии | Нужна другая сессия (например 0x4F) |

## SFD

На MQB‑Evo (A3 8Y, Golf 8, Octavia 4, Leon 4) блоки 09, 17, 19, 5F, A5, 44, 4B, иногда 13/76
защищены SFD: чтение свободно, запись — только после разблокировки, которую выдаёт сервер VW через
авторизованный инструмент (OBDeleven Pro/Ultimate, VCDS с токеном, ODIS с GeKo). Разблокировка
действует ограниченное время (около 90 минут). Сообщают, что запись другим инструментом в это окно
проходит (технически блок не различает тестеры на шине), но гарантий нет — проверяйте.

Новые машины (с ~2024–2025 г.) могут иметь **SFD2**: там подписывается каждая отдельная запись,
и сторонняя запись в окно разблокировки невозможна в принципе.

VagOn **не обходит** SFD/SFD2, защиту компонентов, иммобилайзер и не правит пробег.

## Чего VagOn не делает никогда

* Прошивка блоков (программирующая сессия 0x02, загрузка данных) — запрещено в коде.
* Запись в иммобилайзер (25), подушки безопасности (15), блокировку рулевой колонки (2B).
* Подбор логин‑кодов перебором.
