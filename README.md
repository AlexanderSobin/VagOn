# VagOn

Кодирование и адаптации блоков VAG (Audi / VW / Škoda / Seat / Cupra на MQB и MQB‑Evo)
через обычный **ELM327** — на **MacBook** и **iPhone**. Сделан под **Audi A3 8Y**, но работает с
любыми UDS‑блоками VAG.

То же, что делают ODIS / VCDS / OBDeleven при «Кодировании» и «Адаптации»: чтение и запись длинного
кодирования, каналов адаптации, ошибки, идентификация блоков — плюс готовые рецепты твиков,
режим обучения, резервные копии и откат.

```
vagon -a wifi scan                          # найти все блоки
vagon -a wifi recipe check mmi.wireless_carplay
vagon -a wifi recipe on cockpit.needle_sweep
vagon web --open                            # веб-интерфейс (на iPhone — в Pythonista)
```

> **Только для личного использования на своём автомобиле.** Всё на ваш риск: перед каждой записью
> VagOn сохраняет резервную копию и после записи проверяет результат чтением, но кодирование —
> это всегда вмешательство в настройки блоков.

## Важно про Audi A3 8Y: SFD и «метки каналов»

1. **SFD (Schutz Fahrzeug‑Diagnose).** На MQB‑Evo большинство интересных блоков (09, 17, 19, 5F,
   A5, 44, 4B…) защищены: читать можно, а запись разрешается только во время **разблокировки SFD**,
   которую выдаёт сервер VW через авторизованный инструмент (OBDeleven Pro/Ultimate, VCDS с токеном,
   ODIS с GeKo). VagOn **не обходит** SFD — он распознаёт защиту и честно об этом сообщает. Если вы
   разблокировали блок легальным способом, сразу же можно писать из VagOn (окно разблокировки —
   около 90 минут).
2. **Метки каналов.** Блоки VAG не сообщают имена своих адаптаций: связь «имя канала → DID и биты»
   (например `5F → Apple_DIO_Wireless`) хранится в базах ODIS/VCDS, и публично её нет. Поэтому:
   * рецепты на **длинном кодировании** (байт/бит) работают сразу;
   * рецепты на **адаптациях** (беспроводной CarPlay, анимация фонарей RS3, Start/Stop, меню MMI…)
     становятся рабочими после того, как VagOn **один раз выучит** канал на вашей машине —
     см. [режим обучения](docs/LEARN.md). С вашим VNCI это удобно: делаете изменение в ODIS один раз,
     VagOn сравнивает снимки «до/после» и запоминает точный DID и биты для **вашей** версии ПО.

Ни один рецепт в комплекте не проверен авторами на реальной 8Y — у каждого указан источник и статус
(`community-mqb`, `needs-labels`…). VagOn всегда показывает план записи байт‑в‑байт перед применением.

## Быстрый старт

### Mac
```bash
git clone https://github.com/AlexanderSobin/VagOn.git && cd VagOn
python3 -m pip install -e ".[all]"       # bleak (BLE) и pyserial (USB/Bluetooth) — по желанию
vagon -a sim scan                          # тренировка на симуляторе
vagon -a wifi info                         # Wi‑Fi ELM327 (подключитесь к его сети)
vagon web --open                           # веб‑интерфейс в браузере
```
Подробно: [docs/MAC.md](docs/MAC.md).

### iPhone
Нужен **Pythonista 3** (App Store) и **BLE** или **Wi‑Fi** ELM327 (iOS не умеет классический Bluetooth).
Скопируйте `scripts/ios/install_vagon.py` в Pythonista и запустите — он скачает VagOn; затем
запускайте `VagOn.py`: интерфейс откроется на весь экран. Подробно: [docs/IPHONE.md](docs/IPHONE.md).
Есть и вариант без покупок — **a‑Shell** (только командная строка и Wi‑Fi адаптер).

## Как пользоваться (порядок для первого раза)

1. Зажигание **ВКЛ**, двигатель **ВЫКЛ**, лучше с зарядным/бустером (запись при < 12 В — плохая идея).
2. `vagon info` — проверка адаптера (подходит ли он для VAG), напряжения, VIN.
3. `vagon scan --dtc` — список блоков и ошибок.
4. `vagon backup-all` — копия кодирования всех блоков до любых изменений.
5. `vagon recipes --check` — какие функции уже включены, какие доступны, каким нужно обучение.
6. `vagon recipe check <id>` → смотрите план → `vagon recipe on <id>`.
7. Что-то не так — `vagon recipe off <id>` или `vagon backups` → `vagon restore <файл>`.

**Пошагово для 8Y** (CarPlay, анимация фонарей, Coming home, стрелки): [docs/GUIDE_8Y.md](docs/GUIDE_8Y.md).

Все команды: `vagon --help`, `vagon <команда> --help`. Справочник — [docs/COMMANDS.md](docs/COMMANDS.md).

## Рецепты в комплекте (Audi A3 8Y)

| id | Что делает | Блок | Тип |
|---|---|---|---|
| `mmi.wireless_carplay` | Беспроводной Apple CarPlay | 5F | адаптации, SFD |
| `mmi.wireless_android_auto` | Беспроводной Android Auto | 5F | адаптации, SFD |
| `mmi.developer_mode` | Инженерное меню MMI (сессия 0x4F, логин 20103) | 5F | адаптация, SFD |
| `mmi.menu_*` | Пункты меню «Автомобиль» (знаки, Start/Stop, усталость, потребители) | 5F | адаптации, SFD |
| `lights.rs3_taillight_animation` | Анимация задних фонарей как у RS3 | 09 | адаптация, SFD |
| `lights.allow_lights_off` | Полное выключение света переключателем | 09 | адаптации, SFD |
| `comfort.start_stop_off` | Start/Stop выключен по умолчанию (порог 12.1 В) | 19 | адаптация, SFD |
| `cockpit.needle_sweep` | Приветствие стрелками | 17 | кодирование (байт 1 бит 0) |
| `cockpit.traffic_sign_display` | Знаки в приборке | 17 | кодирование (байт 5 бит 2) |
| `cockpit.lap_timer` | Секундомер в Virtual Cockpit | 17 | адаптация, SFD |

Свои рецепты — JSON в `~/.vagon/recipes/` (iPhone: `Файлы → Pythonista → VagOn/recipes`),
формат — [docs/RECIPES.md](docs/RECIPES.md). Режим обучения создаёт их сам.

## Безопасность — что VagOn делает и чего не делает

* Перед **любой** записью: свежее чтение, резервная копия файла (идентификация + все изменяемые DID),
  затем — запись, обратное чтение и сравнение. Журнал всех записей: `vagon journal`.
* Пишет данные мастерской F199/F198 перед кодированием (как ODIS/VCDS — без этого блоки отвечают
  `requestSequenceError`).
* Логин‑код пробуется **один раз**; неверный код больше не повторяется (у блоков есть счётчик попыток).
* Никогда не пишет в иммобилайзер (25), подушки (15), блокировку руля (2B).
* **Не делает**: прошивку блоков, обход SFD/SFD2, защиты компонентов, иммобилайзера, правку пробега.

Подробно: [docs/SAFETY.md](docs/SAFETY.md).

## Как это устроено

```
vagon/
  transport/   ELM327 драйвер (ISO‑TP вручную, правильный flow control для VAG), Wi‑Fi/serial/BLE
  isotp.py     ISO 15765‑2;  uds.py — ISO 14229 клиент
  vag/         блоки и CAN ID, идентификация, кодирование, логин, запись с копиями, обучение, метки
  recipes.py   рецепты → точный план записи
  web/         локальный веб‑интерфейс (без интернета, работает в Pythonista)
  sim/         эмулятор ELM327 + Audi A3 8Y (тесты и тренировка)
```
Технические детали (CAN ID, последовательность записи, ловушки ELM327): [docs/TECH.md](docs/TECH.md).

Тесты: `python3 -m pytest` (≈90 тестов, включая сквозные через эмулятор ELM327; Python 3.10+).
